# Pico Reader

[English](README.md) · [简体中文](README.zh-CN.md) · [Third-party notices](THIRD_PARTY_NOTICES.md)

MindReset Read Pico（RDP-G01-W）向けの独立したオープンソース読書ファームウェアです。[MindReset の公式デモ](https://github.com/MindReset/read_pico_firmware)を基にしていますが、**MindReset の公式リリースではありません**。

EPUB と TXT の読書、読書位置の保存、TF カードのファイル管理、Wi-Fi・ホットスポット・USB での転送に対応します。[HTTPS オンライン書き込みページ](https://wegooo-cell.github.io/read-pico-reader/)は PC 版 Chrome または Edge と USB データケーブルで利用できます。書き込む前に基板型番を確認してください。通常の書き込みでは設定、読書記録、TF カードの内容を消去しません。

オンライン書き込みではブートローダー、パーティションテーブル、アプリ、OTA データ領域を書き込みます。既存の NVS 設定と内部の書籍領域は維持されます。書棚の「表紙と背表紙」モードは**テスト版（正式版ではありません）**として表示します。[更新履歴](docs/CHANGELOG.md)も参照してください。

このファームウェアを使用中で自動的にダウンロードモードへ切り替わらない場合は、本体の「设置 → 升级和恢复 → BOOT 刷机 → 进入 BOOT 模式」を選び、PC がシリアルポートを再認識してから書き込みページで再試行してください。

Wi-Fi 接続後、本体の「设置 → 升级和恢复 → 系统升级 → 检查更新」でオンライン更新を確認できます。rc84 以降は、新版の短い更新履歴と「稍后 / 开始更新」ボタンを表示します。旧版から rc84 に更新する場合は、書き込みページで今回の更新履歴をご覧ください。

TF カード内の任意のフォルダーから TXT/EPUB を開いて読書位置を保存すると、再スキャンせずに書棚へ追加されます。書棚管理の「移出书架」は項目を非表示にするだけで、ファイル・読書位置・お気に入りは残します。再び読むと書棚へ戻ります。非表示の状態は本体に保存し、設定のバックアップと復元にも含めます。

EPUB の本文の各章は新しいページから始まり、収まる場合は章題と冒頭の本文を同じページに表示します。一つの XHTML 内の複数の章も対象です。目次リンク、紹介文、著者・著作権情報は本文の章として扱わず、通常の小見出しは続けて表示します。章の検出には目次、番号付きの独立した章題と本文構造を使うため、適切なマークアップのない書籍は個別の互換性対応が必要になる場合があります。

振ってページ送りは標準では無効です。読書の字体設定で有効にすると、左方向の動作で前ページ、右方向で次ページへ進みます。ゆっくりした傾き、上下方向、タッチ中と反動は除外し、動作後は 800 ミリ秒の待ち時間と静止が必要です。実機で方向と感度を確認してください。全体の高速更新テスト項目は削除し、古い設定からも有効化しません。

## 現行リリース：rc86

統一キーボード、連続ピンインとオフライン単語候補、カーソル、キーの押下表示、長押し連続削除を追加しました。候補欄の残像と EPUB の互換性を改善し、WiFi・ホットスポット転送画面からステータス署名を保存できます。USB・TF・オンライン更新に同じビルドを提供し、端末で短い更新履歴を確認できます。詳細は[更新履歴](docs/CHANGELOG.md)をご覧ください。

## 入力方式

九宮格は中国語ピンイン専用で、英語と大文字・小文字の切り替えは全キーボードで使用します。数字は「123」画面から入力します。削除キーを約半秒押し続けると、未確定のピンイン、カーソル前の文字の順に連続削除します。指を離すかキーの外へ動かすと停止し、通常の入力と削除は変更範囲だけ更新します。候補欄が6回変化した後、指を離して約700ミリ秒停止すると、その欄だけを一度グレースケール更新して残像を抑えます。連続入力や削除キーの長押し中は延期し、キーボードの切り替えや画面終了で取り消します。キーを押すと濃くなり少し沈み、離すと元に戻ります。488 個のオフライン単語候補、同音字の継続ページ送り、九宮格の「更多」による読み選択に対応します。内蔵黒体は GB2312 の漢字 6763 字をカバーし、TF カードのフォントは不要です。WiFi パスワードは英語全キーボード・数字・記号を使用します。これらの機能は rc86 リリースに含まれています。

## TF カードからのローカル更新

最初に一度だけ、PC から OTA 基本版を完全に書き込み、ブートローダーと二つのファームウェア領域を導入します。既存の設定、読書記録、内部ストレージの位置、TF カードの内容は維持されます。その後はアプリケーション画像を `Pico-update.bin` という名前で TF カード直下に置き、「ファイル → 更新 → 更新をインストール」から更新できます。

本体は画像のプロジェクト名、バージョン、サイズとヘッダーを確認し、未使用側の領域だけに書き込みます。完全性の確認後に起動先を切り替え、新しい版が初回起動確認前に異常終了した場合は以前の版へ自動的に戻ります。更新中は電源と TF カードを外さないでください。アプリケーションだけの更新では、最初の OTA 基本版導入やパーティション表の変更はできません。

ビルドには ESP-IDF v6.1 が必要です。ファームウェアには Noto Sans SC Medium のサブセットのみを内蔵し、追加のフォントや書籍は配布しません。

本体の上流コードは Apache-2.0、UI アイコンは Lucide（ISC）、epdiy は LGPL-3.0-or-later、内蔵フォントは SIL OFL 1.1 に従います。適用範囲は [第三者ライセンス一覧](THIRD_PARTY_NOTICES.md)をご覧ください。

### WeRead の一括ダウンロード

本棚の複数選択はページをまたいで保持されます。一括ダウンロードは 1 冊ずつ実行し、終了・キャンセル・ロック時は待機中の処理を停止して完了済みファイルを残します。表紙は本文挿絵の設定に関係なく取得します。ファイル名は本棚の書名を使用し、ファイルシステムで禁止される文字のみ置換します。1 回の選択上限は 1024 冊です。書籍詳細から本棚へ、本棚からファイル管理へ戻ります。

## 本棚とページ送りの追加スタイル

設定 → 本棚スタイル →「清晰书单」は、1ページ5冊、大きな2行タイトル、著者と読書進捗を表示します。読書設定 → ページ送り効果 →「快速水波纹」は、元の波形と全位相を維持し、ソフトウェアの目標間隔のみ21msから14msに短縮します（52ステップで約0.73秒、従来は約1.09秒。走査が遅い場合は長くなります）。既存スタイルと既定値は維持され、定期的な全画面リフレッシュが優先されます。高速化は全画面リフレッシュの代わりにはなりません。このソース追加は公開済みrc86バイナリにはまだ含まれていません。
