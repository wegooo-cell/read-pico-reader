METALIO / ESP32-S31

Metalio 安装与升级

仅适用于 EINK 4 Plus V1.5、34Pin、E0470A14-AF、ESP32-S31。此包不能用于小纸 Pico。

网页 USB 安装

支持直接从当前 S31 固件刷入，无需先恢复官方系统。进入 BOOT 下载模式后连接设备，页面会核对目标固件、芯片、分区和启动记录。兼容分区默认保留机内设置。

  1. 在电脑 Chrome 或 Edge 打开官网 Metalio 刷机页。确认设备卡片与手中板型一致。
  2. 在设备的「设置 → 升级和恢复 → BOOT 刷机」进入下载模式，用数据线连接电脑。退出 USB 读卡模式，关闭其他串口监视器或刷机页面。
  3. 按需要选择是否清除机内设置，再点「连接并刷入」，选择 Espressif 下载串口。页面先验证固件包、S31 芯片、分区和启动记录，随后直接写入。
  4. 已有兼容 kiikoread 默认保留机内设置、分区和启动位置。不做刷前应用备份；写后在设备端计算 MD5，与已验证的固件文件比较。校验失败会停止。
  5. 首次安装需要切换分区时，需明确勾选「清除机内设置」。页面根据实际分区选择基础包安装。Wi-Fi、蓝牙、锁屏密码等机内设置会清除，TF 文件保留。
  6. 页面显示校验完成后查看设备是否开机。若停在 BOOT，短按复位。握手失败时先排除串口占用、充电线及 USB 读卡模式，不反复擦除整片 Flash。

TF 卡升级

设备已安装独立 S31 双槽基础包时，下载 Metalio 应用 Bin，改名为 Metalio-S31-update.bin 放入 TF 卡根目录，在「设置 → 系统升级」选择 TF 卡升级。只更新空闲应用槽，保留设置与 TF 文件；应用 Bin 不能作为完整包写到地址 0。

联网 OTA

Metalio rc98 起启用联网 OTA。旧本地版需先用 USB 或 TF 安装兼容的 Metalio 基础包；之后连接 Wi-Fi，在「设置 → 系统升级」检查更新。GitHub Pages 为优先来源，官网备用。下载通过 HTTPS、大小、S31 芯片、独立项目和整包 SHA-256 校验后才切换启动槽。校验失败或取消时保留当前启动槽。

设备不需要 GitHub 账号。固件下载和升级清单公开，Metalio 固件源码保持私有。
