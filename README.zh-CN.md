这是为 **MindReset RDP-G01-W** 墨水屏开发板制作的独立阅读固件，源码公开，许可按上述范围分别适用。项目基于 [MindReset 官方示例固件](https://github.com/MindReset/read_pico_firmware) 开发，**并非 MindReset 官方发布**。

界面包括首页、书架、文件管理和设置；可阅读 TF 卡中的 EPUB、TXT，保存阅读进度，并通过 WiFi、设备热点或 USB 传输文件。

## 当前正式版：rc99

基于51e7d8d：恢复系统文字抗锯齿，修复充电显示，新增单击/双击唤醒选项，统一锁屏/取消图标，阅读辅助线随文字范围裁剪，进入阅读完整清理。官网保留原rc98供回退。详见[更新日志](docs/CHANGELOG.md)。


### 阅读与低功耗更新

阅读设置使用已确认的半屏双列排版：点按「自动全刷」轮换5/10/15/30页与不强制，点按「翻页效果」切换普通/水波纹。「翻页模式」「按键控制」进入各自二级页，保留电源键翻页、全屏沉浸与关闭书内图片。手动全刷仍可映射给按键。普通纯文字翻页使用一轮GC16派生刷新，未变化的白底只擦白、不先压黑；正文和页脚同次显示。变化文字保留原GC16迁移，不能等同完整清残影；周期与手动全刷仍使用原表。300ms目标尚未达成。水波纹、插图和阅读背景保留独立路径。阅读水波纹改为8条带，目标节拍11,090 µs；每像素完整执行37相，主页水波纹保持独立参数。

本版合入[官方 a2a63a6](https://github.com/MindReset/read_pico_firmware/commit/a2a63a6a2c606540be72156a6567392d948d65fc)：睡前停用触摸、加速度计和蜂鸣器，收口IO扩展器，浅睡时下拉悬空面板/TF时钟输入并准备CPU保持区。浅睡保留CW_INT输入用于按键唤醒，仅主机下电时改为输出低。保留十分钟锁屏、密码和阅读检查点；PMU交接失败恢复外设，不反复重启或无限等待。实际功耗仍需实机测量。

### 设置、存储与锁屏修复

设置页只绘制可见行并复用小尺寸头像像素；入口箭头独立绘制，导入字体缺少该符号也能显示。卡空间按挂载分区的可用容量和当前分配统计，挂载时重算一次过期的FAT32可用簇提示；统计失败显示暂不可用，不影响卡上文件读取。阅读状态栏按分钟局部更新，正文和隐藏的沉浸状态栏不刷新。

壁纸锁屏将最终16级灰阶抖动画布保存为 `.readpico/locks/wallpaper.bin`：首次生成，后续直接读取并校验。源文件、方向或算法变化及损坏缓存会重建；写入失败仍可正常锁屏，不常驻额外整帧。书架封面加载后保留待显示标记，直到推屏成功才清除，修复缓存已准备好却漏刷封面的路径。


阅读字体设置新增抗锯齿开关，默认开启；只改变边缘覆盖，不改变排版或另存一份字形缓存。阅读时从屏幕底部120像素范围上滑，无论轻点翻页模式或按键配置如何，都打开工具栏。系统设置在100–200%字号下保持名称、值同一行，长值截短；阅读工具栏及二级面板跟随系统字号，双列面板向上展开，文字按控件边界用原始字形适配，绘制和点击位置一致，正文仍使用阅读字号。书架各刷新模式先读取整页已有封面缓存，再一起显示；首次缺缓存时分批处理，完成后整页一起显示，失败封面保留占位。保持原来的缓存格式释放和切页打断规则。

## 主页刷新与阅读按键

“设置 → 显示 → 主页刷新模式”可选普通、快刷、水波纹，默认普通。普通与水波纹保留灰阶；快刷采用黑白封面和细腻棋盘格亚克力。四个主页面保留底栏图标与文字，小横条单独局部移动；三种模式的点击反馈保留原灰色背景。

主页水波纹采用与阅读相同的紧凑节奏：8条带、44拍、11,090µs目标节拍，每像素完整37相。软件目标从此前624ms缩至约488ms，实际切换还包含绘制和扫描时间；保留主页原灰阶序列、固定底栏和失败恢复，实屏灰阶与残影仍需验收。

列表封面点击时轻轻上弹并回位后开书，只局部更新封面移动范围；快刷使用黑白差分，普通和水波纹保持灰阶，避免额外黑框。

从屏幕顶部边缘下滑打开快捷菜单，可连接最近保存的 WiFi / 再次断开、切换蓝牙、全刷和锁屏。向上滑、点外部或返回键收起；传书忙碌时保持网络。

“阅读设置 → 按键控制”可自定义三键短按及中键长按，并选择两套推荐：设置1为左上一页、中阅读工具栏、右下一页；设置2为左首页、中切换全屏、右阅读工具栏。中键长按默认返回首页，也可设为返回首页等功能。从屏幕底部上滑固定呼出工具栏，不随翻页模式或按键设置改变。四种按键操作均可设成其他功能；启动和恢复配置时保持自定义映射。中间单击只进入全屏；两侧单击翻页，上下翻页模式保留对应区域。新开书默认非全屏并显示工具栏，翻页保持当前模式；底部上滑退出全屏并显示工具栏。配置随重启及保存恢复保留。

本版包含：锁屏前保存书籍、阅读位置和全屏状态，深睡开机只尝试恢复一次；打开书籍被断电或异常重启打断后，显示书名与返回首页、确认删除选项，停止自动重试该书。票根从任意页面锁屏均使用系统字体，浅睡解锁恢复此前阅读字体。三种主页模式的快捷面板均用灰阶和清晰框线。快刷只缓存黑白封面，普通及水波纹只缓存灰阶封面，切换时释放旧格式。首页续读书名复用系统字体，阅读页书名与章节标题复用阅读字体，分别按原40、32、48像素直接生成字形；不为标题增加内建字库或同时加载系统与阅读字体。未选字体或字体不可用时保留安全的内建缺字回退。以上改动已包含在 rc88 正式版中。

## 输入法

文件改名、资料卡名称、状态栏签名、书架搜索和 WiFi 密码使用统一键盘。九宫格只输入中文拼音，全键盘支持「中 / En」和英文 a / A 大小写切换；数字统一在「123」页面输入。中文支持连续拼音和 487 个离线常用词组，点击候选提交；同音字可用候选箭头持续翻页，九宫格左侧「更多」可切换读音；未知词可分段选字，拼音未确认时不会直接保存。轻点输入框或其中的左右箭头定位光标，在当前位置插入或删除。长按删除键约半秒后连续删除，先删待选拼音，再删光标前的文字，松手或移开停止；普通输入和删除仅局部刷新。候选词栏累计变化六次后，停手约 700 毫秒会做一次局部灰阶整理，减轻残影；持续打字、按住删除时延后，切换键盘或离页取消。按下按键会加深并轻微下沉，松开恢复；内建黑体补齐 GB2312 的 6763 个常用汉字，不依赖 TF 字体包。WiFi 密码仅允许英文、数字和符号，使用全键盘。

WiFi 和热点传书网页都有「状态栏签名」，保存或清空后写入设备配置，重启仍保留。签名最多 95 个 UTF-8 字节（约 31 个汉字）。以上功能包含在 rc86 正式版中。

## 文件传输

文件管理直接显示 **WiFi传输、热点传输、USB传输** 三个入口。WiFi 传输连接已保存的网络，未配网时进入网络设置；热点传输直接创建 kiikoread 热点；USB 传输连接电脑读写 TF 卡。WiFi 与热点网页继续支持 TF 卡目录浏览、任意文件上传、书籍/字体/图片导入和状态栏签名设置。

## 升级和恢复

### 电源与设置拖动

长按电源键进入电源选项，抓住上方圆形电源图标向右拖动，到达轨道的92%后松手确认关机；未到确认位置则回到起点。下方两个圆钮分别是重启、取消，取消返回原页面。关机继续遵循「关机睡眠」设置。拖动仅更新滑块经过的局部区域，多指触摸或输入中断会取消本次确认。

系统设置、蓝牙翻页器及设备扫描列表采用分段滑动：垂直移动超过阈值后推进一段列表，同一手势只更新一次，松手后立即停在当前位置。普通、快刷、水波纹三种主页模式都沿用此操作，内容区使用原灰阶差分刷新，题头与底栏保持固定。

书架题头可选择「全部书籍」「未分类」或 books 下的子文件夹；更深层的书归入上一级类别。各类别分别记住封面书架和列表书架的页码，切换主页面后返回仍停在原位置。书架题头不再绘制横线，层板和封面保持统一位置。首页静止时按分钟局部更新时间；解锁恢复页面时完整清理一次残影。

系统设置的“升级和恢复”分组包含系统升级、保存与恢复、BOOT 刷机。文件管理专注文件与传输；蓝牙翻页器可在设置里启用、配对与学习按键。只支持 BLE 设备，WiFi 工作时暂停蓝牙。

官网下载的 `Pico-update.bin` 放在 TF 卡根目录，然后选择“设置 → 升级和恢复 → 系统升级 → TF 卡升级”。rc72 及以后的现有双槽基础包兼容本次 TF 升级；更早版本或其他固件先完整刷机。rc79 新增联网 OTA，官网发布后续清单后可通过 WiFi 检查与升级。

每次发布运行 `python3 tools/package_flash.py build/版本号 flash`，从同一编译输出生成全量包、TF Bin 和 OTA 清单；网页部署前再次核对设备型号、双槽布局、基础包版本与能力、Bin 大小及 SHA256。分区或基础升级能力不符合要求时拒绝发布，需重新生成兼容基础包。

## 在线网页刷机

连接按钮上方可选择最新正式版或原发布的 **rc86 / rc85**，发布时间与 TF 升级 Bin 下载跟随选择。所有版本默认保留设备数据。

打开 [HTTPS 在线刷机页](https://wegooo-cell.github.io/read-pico-reader/)。在电脑端 Chrome 或 Edge 中，用支持数据传输的 USB 线连接 **RDP-G01-W 墨水屏**，选择设备串口并按提示刷入。**刷机前确认型号。**普通刷机保留设备设置、阅读记录和 TF 卡内容；固件不附带书籍或预设的阅读记录。

如果运行本固件的设备无法自动进入下载模式，可在设备上点击**设置 → 升级和恢复 → BOOT 刷机**，等电脑重新识别串口后再用网页刷机。

刷机页现有图文新手指南：**连接 kiikoread → 选择串口 → 确认安装并等待完成**。页面下方也介绍了首页、书架、文件管理和设置，以及常见问题。

刷机清单为 [`flash/manifest.json`](flash/manifest.json)，写入引导程序、分区表、应用程序和 OTA 数据分区；不会覆盖现有 NVS 设置与内置书籍分区。网页由 [Pages 工作流](.github/workflows/pages.yml) 按明确的文件清单部署，不上传本机书籍、备份或额外字体包。[查看更新日志](docs/CHANGELOG.md)。

阅读 → 字体设置 → 阅读背景，先打开 TF 卡 `pictures` 图片目录，过滤 Mac `._` 和其他隐藏文件。点选 JPG/JPEG/PNG 进入预览，上下滑动切换，返回保留目录位置；使用背景保存，取消不改已选项，无背景恢复白底。背景固定铺满整屏，不随边距和全屏变化，文字叠加其上。按屏幕原尺寸保留原图灰度和细节，不强制淡化；预览和实际阅读使用同一份16灰阶缓存，翻页直接复用。推荐 **684×1216** 竖屏、不透明浅色非交错8位灰阶PNG或普通JPG，建议1MiB以内以缩短加载。缺失、解码失败或内存不足时回退白底。已删除晃动翻页。

书架封面处理后保存在TF卡隐藏目录 `.readpico/covers`：普通/水波纹直接复用灰阶缩略图，快刷额外保存最终黑白点阵，后续加载跳过解码、缩放和抖动转换。书源身份、尺寸、对比度和抖动相位变化或缓存损坏时重新生成；首次没有缓存仍需要处理。选择拼贴锁屏后，书架空闲时每次预生成一本有界封面到 `.readpico/locks`，锁屏复用原比例封面及校验过的完整画面，保持原画质。缓存可删除，不是原书文件；TF卡写入失败不会阻止阅读。

## 联网升级

连接 WiFi 后进入**设置 → 升级和恢复 → 系统升级 → 检查更新**。从 rc84 开始，发现新版本时会显示简短更新日志，并提供“稍后 / 开始更新”。旧版固件升级到 rc84 前，可在在线刷机页查看本次日志。

本地修复：联网升级前释放闲置封面缓存，内存不足时停止并提示；屏幕推送和固件擦写串行执行，按下载顺序分段擦除。下载进度约每 5 秒且增长至少 5 个百分点时，仅补画新增黑色段和百分比，不擦除已完成段、不累计整页清屏。离页、锁屏和取消仍等待任务收尾，校验失败保留当前启动槽。

## TF 卡本地升级

启用本地升级时，需要先用电脑完整刷入一次带双分区的 OTA 基础版；这一步会更新引导程序和分区表，但保留原来的设备设置、阅读记录、内部存储地址与 TF 卡内容。之后把对应设备型号的应用镜像命名为 `Pico-update.bin`，放到 TF 卡根目录，进入**设置 → 升级和恢复 → 系统升级 → TF 卡升级**。

设备会先检查固件项目名、版本、文件大小和镜像头，再把升级包写入当前未使用的固件槽。完整性校验通过后才切换启动槽；新版本首次启动如果未通过硬件与界面检查便异常复位，引导程序会自动回到上一槽。安装过程中请保持供电，不要取出 TF 卡。TF 卡升级包只包含应用程序，不能代替首次安装 OTA 基础版，也不能用于更换分区表或引导程序。

## 自行编译

仓库只有一份共享的 `main/` 与 `components/` 源码；`boards/<板型>/` 提供硬件后端、sdkconfig、分区表和依赖锁。用 `--board pico|metalio47` 选择设备，并准备对应的 ESP-IDF **v6.1** SDK：

```sh
python3 tools/build_firmware.py --board pico --python /path/to/idf-python/bin/python
python3 tools/build_firmware.py --board metalio47 --python /path/to/idf-python/bin/python
```

Pico 是 ESP32-S3（Xtensa），Metalio 是 ESP32-S31（RISC-V）；两者需要各自的 SDK/工具链、配置和输出目录，固件不能跨板型刷写。Windows 可运行 `tools\build_board.ps1 -Board pico|metalio47`。完整构建矩阵、分区表和烧录地址见 [docs/BOARDS.md](docs/BOARDS.md)。预编译固件仅面向 RDP-G01-W。

## 书籍与字体

TF 卡当前支持 FAT16/FAT32，未启用 exFAT，容量大小本身不代表已验证兼容。本地开发版在 40 MHz 初始化失败后等待 250 毫秒再试，再依次降至 20/10 MHz，包含高速协商忙碌错误。卡检测通信失败保留原快照，不误判拔卡；无法读取检测信号时允许有界的实际挂载尝试。初始化失败不会自动建议格式化或清空卡内容。实际拔卡仍会使原文件状态失效，须停止文件使用后显式重挂，或重启设备重新识别。

首次挂载 TF 卡时，固件会按需建立 `books`、`fonts`、`pictures` 文件夹，不会预装书籍。系统界面内建 **思源黑体 Medium 子集**，除此之外不提供字体包。用户可自行把兼容字体放入 TF 卡的 `fonts` 文件夹，供阅读正文选择。内建字体遵循 [SIL OFL 1.1](main/assets/OFL-Noto.txt)。

书架样式保留「深色书轨」和「亚克力书架」，每页 9 本。旧配置或配置备份中的「半透明书袋」「封面与书脊」会回退为亚克力书架。

本地开发版新增 **设置 → 锁屏样式 → 书架拼贴**：使用真实封面，保留原始宽高比、圆角及统一 15° 倾斜；最近阅读的书位于中间。左上显示资料卡名称加“的书架”，右下显示大号书籍数与小号“本”。文字使用选中的系统字体原生轮廓，不复用阅读字体；浅睡解锁恢复原字体。拼贴始终采用 16 级灰阶和稳定抖动，不随主页快刷变为黑白。缓存保存在 TF 卡的 `.readpico/locks`，名字、字体或书架内容变化后重建；首次生成需要处理封面，内存不足时使用安全锁屏画面。

浅色拼贴封面增加细灰色圆角描边，保持白底上的边界清晰。**设置 → 个性化功能 → 锁屏密码**可开启四位数字密码，默认关闭；开启需两次输入一致，修改或关闭需验证原密码。浅睡唤醒、深睡及冷启动均先验证，再回到此前页面。按下数字圆键预览输入，有效松手才提交；「取消」回到锁屏画面并继续锁定，「删除」退一位。实际锁屏图使用较轻模糊并只缓存一次；唤醒或冷启动时一次显示完整密码页，圆角锁图标和控件保持清晰，输入时不继续刷新模糊背景，按键反馈局部刷新；文字使用选中的系统字体，字体不可用时保留内建回退。设备仅保存加盐摘要；普通配置备份不包含、恢复时也不覆盖密码凭据。

自动休眠和手动锁屏均使用当前选中的锁屏样式。密码背景缓存只复用匹配当前样式与壁纸身份的画面；切换样式或更换壁纸后，深睡唤醒/冷启动重画当前选择，密码保护不受影响。选择壁纸模式需在壁纸预览中确认图片。

从文件管理打开 TF 卡任意目录中的 TXT/EPUB 并保存阅读进度后，返回书架会自动收录，无需重新扫描。书架管理的「移出书架」只隐藏所选条目，保留文件、阅读进度和收藏；再次打开阅读后自动重新上架。移出状态会记住，并随配置备份保存、恢复。

书架管理沿用文件管理布局：顶部切换列表/图标，下面是搜索框、书籍数量、「书架排序」和选择，不再显示来源筛选。普通点按开书；长按书籍或点「选择」才显示圆形待选标记与删除书籍、清理进度、移出书架、返回四项操作，返回先退出选择。分页、排序和切换视图保留已选书籍；应用搜索清空选择。分页支持最前、上一页、下一页、最后；列表每页五本，图标每页六本，三类批量操作仍需确认。

TXT 或没有有效内嵌封面的 EPUB 会按书籍路径稳定生成灰阶封面；书架、首页和阅读票根显示同一版式。有效的 EPUB 原封面仍优先使用。生成结果缓存在 TF 卡的 `.readpico/covers` 中，文件或书名变化后会重新生成。

首次开机没有插 TF 卡时，之后插卡会自动探测并更新首页、书架与文件管理。已挂载的卡请勿在阅读或传输时直接拔出；若已拔出，请插好卡后重启设备，以免旧文件句柄误写。

阅读时双击正文中间区域切换全屏，默认按屏幕下方中间触控键打开阅读工具栏，长按中键默认返回首页；短按与长按动作可在「阅读设置 → 按键控制」自定义。全屏底部有一条细的全书进度线，正文会利用更多底部空间。字体设置主面板可调整字号与阅读线，阅读字体和字重并排，书内自带字体开关和排版设置并排；阅读背景入口已删除；点开「排版设置」可调整边距、行距、段距、字间距和首行缩进。字间距默认位于滑轨中间；首行缩进可选无、1 字、2 字或 3 字，默认 2 字。“缩进微调”以1像素调整首行位置（-20～+20，默认0）；点数值复位，选择无缩进时不生效，随重启及备份恢复保存。边距滑轨按当前字体大小和字间距合并实际宽度相同的档位，每次切到其他档位都有可见变化；已有边距在重画设置页时保持。正文会把可容纳的整列文字居中，避免右侧留白明显宽于左侧；常见中文句末标点不会单独排到下一行开头，左括号和左引号不会留在行尾。点开「阅读线」二级面板可选择无、虚线和点线，并用「上移」「下移」每次微调 2 像素。阅读工具栏中的「阅读设置」可选择每 5、10、15、30 页全刷，或选「不强制」关闭定期全刷；手动全刷始终可用。同一页面可开启电源键翻页（阅读正文短按下一页、长按锁屏）、全屏沉浸（全屏时隐藏状态栏）、关闭书内图片，并设置翻页区域和按键控制。退出全屏后可点击题头左侧圆形返回键回到进入书籍前的页面。以上选项加入 TF 卡配置备份。首行缩进以所选字体的实际字宽计算，段首引号、括号按可见边缘对齐。

需要备份个性化设置时，进入**设置 → 保存与恢复 → 保存当前配置到 TF 卡**，文件保存在卡根目录的 `Pico-settings.backup`。再次刷机或换设备后，把该文件放回 TF 卡根目录，在同一页面选择**从 TF 卡恢复配置**并再次确认。备份包含系统与阅读字体、字号、排版、显示、锁屏、设备名称、头像路径、状态栏签名、已保存的 WiFi 名称与密码，以及每本书的阅读进度、阅读时长、书签、收藏、自定义书名和移出书架状态。书籍、字体、头像和壁纸图片仍留在 TF 卡，不会复制进备份。备份文件含明文 WiFi 密码，请妥善保管 TF 卡；外部图片或字体已不存在时，会回退到默认显示。旧版备份仍可恢复，但不会改动当前的网络配置。

大型 EPUB 的章节、目录和清单按实际数量分配内存；ZIP 条目与章节分别有 8,192 项上限，书籍还需为封面、图片和目录留出条目。整本文件可以大于 32 MB，但单个正文文件仍限定为 4 MB、单张解压图片限定为 8 MB，且受设备剩余内存与普通 ZIP 格式限制。

Pico普通及图文翻页沿用正文GL16，但只刷阅读内容区，顶部状态/标题不随翻页擦白；底部章节与进度在停下800ms后局刷，与水波纹/速读对齐。入书、手动和周期清理保留。

EPUB 内嵌 GIF 显示白底首帧；ROM JPEG 解码失败时用 JPEGDEC 小尺寸平面兜底。支持的同章脚注图标可点按弹出附近卡片，再次点按关闭，阅读位置不变。

EPUB 正文每章从新页开始，章节标题与正文开头同页；同一正文文件内的多个章节也按已识别题头分页。目录链接、简介、作者与版权信息不会仅凭标题被拆成正文章节，普通小节继续接排。章节识别依据书内正式目录、独立编号题头及正文结构；缺少有效标记的 EPUB 可能仍需逐书兼容处理。

首页续读使用原比例圆角封面及阅读进度，点击卡片继续原来的阅读位置。封面复用TF灰阶缩略图，快刷只保留不超过5280字节的黑白封面；模式切换释放旧格式，低内存或缓存损坏时安全回退。

首页左下方默认显示最近读过的三本书组成的磨砂书夹。单击书夹进入书架，单击时钟进入同款大时钟时间页；长按组件进入选择页。左右滑动或两侧箭头循环浏览五款，点「使用此样式」才保存并回首页，返回取消浏览。书夹与原 IKEA PS 1995 的选择兼容保留，新增 Asterisk Clock、Moon Clock、Kehai Clock，选择掉电保存并随配置备份恢复。

书夹缓存最多56KB灰阶或14KB黑白，临时合成缓冲用完释放。新时钟的静态表盘压缩在只读固件资源中，逐行解码仅需135字节工作区，不保留整页或额外加载字体。长短指针按分钟更新，Kehai 的独立圆点秒针在首页、选择页和时间页可见时按秒局部更新并恢复旧圆点位置；时间页数字秒数单独刷新。触摸、切页和锁屏暂停无用更新。上方完整书摘来自已成功打开、解析的书籍正文缓存；没有可用短句时留空。

普通与水波纹模式的续读卡使用浅灰底；三种模式的卡片、书夹、目标胶囊和组件选择框线均向内加粗。快刷书夹与时钟使用固定的细棋盘格填色，机身和袋身轮廓保持实黑。续读文字按实际卡片底色进行原字号抗锯齿；阅读书名与章节标题使用当前阅读字体的灰阶边缘，绘制后恢复正文的抗锯齿开关，不另外加载字体。

点击首页月历或顶部阅读圆环打开月阅读记录，可设置每日5～180分钟目标。达到目标的日期显示下划线，记录最多保留32天并兼容旧30天数据；没有有效日期时不会显示虚构的记录。组件选择与每日目标随配置备份恢复。

系统设置归为「连接与时间」「显示」「个性化功能」「升级和恢复」。日期与时间位于蓝牙翻页器下面；主页刷新模式位于系统对比度下面，自动休眠锁屏和关机睡眠在显示中。书架样式、锁屏样式、锁屏密码和状态栏签名在个性化功能中。系统字体页面合并字号并给出字体预览：点按字号从100%到200%每次增加10%，到200%后回到100%；大字号下名称和值保持同一行。选择系统字体后询问「仅系统 / 同步阅读字体」，只有确认同步才保存阅读字体，当前页面不额外加载第二份字库；保存失败保留原设置并允许重试。

## 开机诊断与屏幕修复

当前源码接入 PR #32–#34，正式附件仍以对应 Release 为准。开机各阶段耗时写入现有 RTC 轨迹，可在概览页「上次运行」查看；首屏完成后停止添加开机标记。竖排阅读辅助线位于字格右侧且各列虚线节奏一致，章节编号与汉字共轴，横线类符号按竖排方向显示。

若刷新中断电后留下持续的黑白条纹，可进入「设置 → 升级和恢复 → 屏幕修复」单击执行。修复会进行多轮整屏黑白驱动，结束后恢复当前画面和底栏；仅在主动点击时运行，不改变日常翻页规则、波形表或 VCOM 标定。若报告输出未完成，可稍后重试。

### 蓝牙翻页器

进入「设置 → WiFi 下一行的蓝牙翻页器」启用、扫描和连接 BLE 翻页器。开启后状态栏显示 Lucide 蓝牙图标，可与 WiFi 图标同时显示。按键映射点击「学习」后，直接按翻页器对应按钮，顶部自动显示「识别成功」及绑定方向，不需要再点屏幕。网络传输、配网及 OTA 期间暂停蓝牙以释放内部内存，网络停止后自动恢复，开关和配对记录保持；暂停时状态栏蓝牙图标变浅。内存不足时拒绝启动并显示原因，主机任务创建失败会回收资源。

### 列表书架与锁屏反馈

“设置 → 个性化功能 → 书架样式”新增“列表书架”，每页四本，封面统一120×156像素，细长封面等比例放大并居中裁切，显示作者、阅读进度与收藏标记；长书名最多两行。翻页、管理与收藏排序仍沿用书架操作，样式支持重启和配置恢复。普通/水波纹缓存灰阶，快刷只保留黑白封面。

列表外框、行间分隔线和常用控件边线采用深色双像素线，在快刷和水波纹模式也可辨认。密码键盘进入时一次显示完整画面，取消二段背景刷新；保留灰阶模糊背景，输入时仅用黑白局部快刷更新圆内反馈和密码圆点，不重新处理背景或字体；删除只退一位，取消仍保持锁定。拼贴封面增加柔和投影，文字白描边减细并自动重建缓存。壁纸、票根及拼贴图像均使用16级物理灰阶加有序抖动表现256级输入亮度；不会变成256级原生屏幕。

阅读「字体设置 → 字重」使用横向胶囊减/加按钮，预览使用当前阅读字体。标准保留原生笔画，其他档保持字形比例与字间距，兼容导入静态字体及 EPUB 书内字体；字重仅用于阅读，不改变系统页面字体，随配置备份恢复。

头像首次裁切后会将原比例灰阶成品存到 TF 卡缓存；首页与资料卡按各自尺寸直接读取，不重解原图。更换或删除源图、缓存损坏时自动重建或回退默认头像。
字重面板用横向胶囊的减/加按钮，每次微调 1/16 像素覆盖率，范围 −2 到 +2 像素，共 65 档；0 保留原始笔画。

## 最新功能界面（未发布，两机同步）

新配置及恢复出厂后进入语言、Wi-Fi、字体引导，已有配置升级不重复引导。系统界面可切换中英文，也可在设置中修改；书名、正文、文件名及输入保留原文。引导通过 U 盘或扫码 Wi-Fi 传输导入 TTF/OTF 字体，返回后重新扫描并分页选择，所选字体同时用于系统与阅读。联网后后台自动对时；保存失败保留引导。

文件支持递归中文、拼音、首字母及英文搜索、列表/图标视图、跨页多选、移动到指定目录与确认删除；移动不覆盖同名目标，失败项保留勾选。书架管理可按名称、最近阅读、首次收录及升降序排列；已有图书在升级后首次扫描登记收录顺序。Wi-Fi 保存最多八个网络并标注可直连；开启蓝牙后尝试重连上次成功使用的已配对设备。

新开书默认非全屏，顶部显示时间、签名和电量，下方为返回键、书名及收藏；底部工具栏进入即显示，章节/进度置于其上方。中间单击只进入全屏，底部上滑返回非全屏并显示工具栏。顶部返回/书名/收藏与底部工具栏共同出现或收起，所有工具栏入口都会先退出全屏。持久化的沉浸开关独立控制全屏样式：关闭沉浸时顶部显示时间、状态栏签名及电量，不显示书名，底部显示章节/章数/百分比，开启后铺屏正文且只保留底部 3 像素进度线。翻页保持模式，切换保留阅读锚点，信息栏空闲后局部更新。底层驱动、供电/睡眠和阅读波形采用 PR #59，保留手动与周期清理，两块板各用自身硬件后端。
